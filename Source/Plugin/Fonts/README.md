# Fontes da interface

- `Sora-400.ttf`, `Sora-600.ttf`, `Sora-700.ttf`, `Sora-800.ttf`: Sora, origem Fontsource (latin), licença OFL (`OFL-Sora.txt`). Uso: textos da interface, via `theme::ui`.
- `IBMPlexMono-400.ttf`, `IBMPlexMono-500.ttf`: IBM Plex Mono, origem Fontsource (latin), licença OFL (`OFL-IBMPlexMono.txt`). Uso: números, via `theme::mono`.
